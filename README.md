هدف المشروع
==================================================

أريد إنشاء موقع حقيقي ومفيد للأساتذة/المكونين والمتربصين/المتمهنين في التكوين المهني.

الموقع ليس موقع وصفات فقط، وليس مدونة.

أريده منصة تعليمية منظمة وفق المقاربة بالكفاءات APC، تجمع برامج التكوين المهني، الوحدات، الكفاءات، الدروس، البطاقات التقنية، المذكرات البيداغوجية، التطبيقات، التقويمات والاختبارات.
